API Guide

Pull payload strings into another scanner or test harness. Every call is an HTTP GET. There is no API key and no search parameter.

Base URL

Use the raw GitHub URL. GitHub Pages serves the same files, and it can keep a previous copy for a few minutes after a push.

https://raw.githubusercontent.com/HarlequinCS/Veritas_Payloads/master/api/v1

Endpoints

page size 1,000
GETReturns
index.jsonTotals, page size, and the endpoint map
categories.jsonEvery category, its slug, count, page count, and first page
categories/{slug}.jsonOne category and its injection-point counts
categories/{slug}/page/{n}.jsonUp to 1,000 payloads, plus next and prev
id-map/{bucket}.jsonPayload id mapped to [slug, page]
sync-log.jsonEach upstream sync and how many payloads it added

Pages start at 1. next and prev are paths relative to the base URL. A missing slug or page returns HTTP 404.

Payload object

{
  "payload_id": "OWP-0055",
  "vulnerability_category": "Injection (SQLi)",
  "target_technology": "MySQL",
  "injection_point": "query_parameter",
  "payload_string": "' UNION SELECT 1,2,3--",
  "validation": {
    "expected_status_code": 200,
    "success_regex": "2.*3"
  }
}
payload_idStable id, OWP- plus a number.
injection_pointWhere to place the string: query, form, header, cookie, body, path, or file upload.
validationStatus and optional response pattern that suggest the check fired.

Slugs

A slug is the category name in lowercase, with spaces changed to _ and parentheses removed. An ampersand stays in the slug, so encode it as %26 in the URL. Read categories.json and encode the slug field. Do not build the long names by hand.

CategorySlug
Injection (SQLi)injection_sqli
Injection (XSS)injection_xss
Injection (LFI/RFI)injection_lfi_rfi
Weak passwordsidentification_%26_authentication_failures_weak_passwords

1. List categories

import requests

base = "https://raw.githubusercontent.com/HarlequinCS/Veritas_Payloads/master/api/v1"
catalog = requests.get(f"{base}/categories.json", timeout=60).json()

for category in catalog["categories"]:
    print(category["count"], category["slug"], category["category"])

2. Read one category, page by page

Stop when next is null. Encode & inside next before the next request.

import requests
from urllib.parse import quote

base = "https://raw.githubusercontent.com/HarlequinCS/Veritas_Payloads/master/api/v1"

def api_url(path):
    return f"{base}/{quote(path, safe='/')}"

url = api_url("categories/injection_sqli/page/1.json")
while url:
    page = requests.get(url, timeout=60).json()
    for item in page["results"]:
        if item["injection_point"] != "query_parameter":
            continue
        print(item["payload_id"], item["payload_string"])
    url = api_url(page["next"]) if page["next"] else None

3. Look up one payload id

Divide the number in the id by 100000. That integer is the bucket file. OWP-0055 is in id-map/0.json. OWP-210845 is in id-map/2.json.

import requests

base = "https://raw.githubusercontent.com/HarlequinCS/Veritas_Payloads/master/api/v1"
payload_id = "OWP-0055"
bucket = int(payload_id.split("-")[1]) // 100000

slug, page_no = requests.get(f"{base}/id-map/{bucket}.json", timeout=60).json()[payload_id]
page = requests.get(f"{base}/categories/{slug}/page/{page_no}.json", timeout=60).json()
record = next(item for item in page["results"] if item["payload_id"] == payload_id)
print(record["payload_string"])

4. Call it from another service

import requests
from urllib.parse import quote

class VeritasPayloads:
    def __init__(self):
        self.base = "https://raw.githubusercontent.com/HarlequinCS/Veritas_Payloads/master/api/v1"
        self.session = requests.Session()

    def url(self, path):
        return f"{self.base}/{quote(path, safe='/')}"

    def categories(self):
        return self.session.get(self.url("categories.json"), timeout=60).json()["categories"]

    def pages(self, slug):
        url = self.url(f"categories/{slug}/page/1.json")
        while url:
            page = self.session.get(url, timeout=60).json()
            yield from page["results"]
            url = self.url(page["next"]) if page["next"] else None

Send payload_string in the location named by injection_point. Compare the HTTP status with validation.expected_status_code. Use a timeout of at least 60 seconds.

5. Daily updates

This repository checks the upstream wordlists at 02:00 Asia/Kuala_Lumpur. The shows how many payloads each run added. A system that caches the files can pull later, at 04:00:

0 20 * * * cd /opt/veritas-consumer && git fetch origin master && git diff --quiet HEAD origin/master || git pull --ff-only origin master

A caller that does not keep a local copy needs no cron. The next GET returns the files on master. To see whether a sync added anything without downloading the dataset, GET sync-log.json and read runs[0].added.

Limits

No authenticationAnyone who can reach the repository can read the files.
No search parameterPage through a category, or resolve one id through the id map.
JSON pagesResponses are JSON, not NDJSON. Page size is fixed at 1,000.
Authorized useUse the payloads only against systems you are allowed to test.
